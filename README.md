# Бэкэнд

### Инициализация базы данных

Функция `init_db()` проверяет наличие файла базы данных `shopping_list.db`. Если файл отсутствует, она считывает содержимое файла `shopping_list.db.sql` и выполняет его, создавая таблицы и заполняя их тестовыми данными. Также настраивается соединение с базой через `get_db_connection()`, чтобы возвращать данные в формате словарей (не кортежей).

### API для Списков покупок

Данный блок реализует полноценные CRUD операции для списков покупок:

* **GET /api/lists** — Возвращает все списки покупок из базы данных.
* **POST /api/lists** — Создает новый список. Принимает JSON с именем списка, сохраняет его с текущей датой.
* **PUT /api/lists/`<id>`** — Редактирует имя существующего списка по его ID.
* **DELETE /api/lists/`<id>`** — Удаляет список и все связанные с ним товары из базы.
* **GET /api/lists/`<id>`** — Возвращает подробную информацию о конкретном списке, включая список товаров с названиями продуктов и магазинов (используется JOIN для объединения таблиц).

### API для товаров в списке

Блок управляет позициями внутри конкретного списка:

* **POST /api/lists/`<id>`/items** — Добавляет товар в список. Принимает ID продукта, ID магазина и количество.
* **PUT /api/items/`<id>`/toggle** — Переключает статус товара (куплено/не куплено) в базе данных.
* **PUT /api/items/`<id>`** — Обновляет количество товара.
* **DELETE /api/items/`<id>`** — Удаляет конкретную позицию из списка.

### Справочные данные (Read Only)

Для обеспечения выпадающих списков на фронтенде реализован только метод чтения:

* **GET /api/products** — Возвращает список всех возможных продуктов (для выбора при добавлении).
* **GET /api/stores** — Возвращает список всех магазинов.

# Фронтэнд

### Инициализация Vue.js

Приложение создает инстанс Vue, который монтируется в блок `<div id="app">`. Используется Composition API (`setup`, `ref`, `onMounted`). Вся разметка обернута в тег `{% raw %}` Jinja2, чтобы Flask не пытался обрабатывать фигурные скобки Vue как свои переменные.

### Управление состоянием (State)

Основные переменные (refs) хранят данные приложения:

* `lists` — Массив всех списков.
* `activeList` — Объект текущего открытого списка (или `null`, если мы на главной).
* `products` и `stores` — Массивы справочников для выбора в формах.
* `newItem` — Объект, содержащий данные из формы добавления товара.

### Навигация и Отображение

Отображение блоков управляется директивами `v-if`:

* Если `activeList` пусто — показывается главная страница со списком всех списков.
* Если `activeList` содержит данные — показывается страница конкретного списка с товарами.
  Это позволяет переключаться между экранами без перезагрузки страницы (SPA).

### Взаимодействие с пользователем

* **Формы:** Поля ввода (input, select) связаны с данными через директиву `v-model`. При изменении значения в поле автоматически обновляется переменная в JavaScript.
* **Списки:** Товары выводятся через цикл `v-for`. Статус "куплено" изменяет визуальный стиль через динамический класс `:class`.

### Асинхронные запросы (Интеграция с API)

Функции фронтэнда используют `fetch` для общения с бэкэндом:

1. **onMounted:** При загрузке страницы вызываются функции `fetchLists`, `fetchProducts`, `fetchStores` для получения начальных данных.
2. **Создание/Редактирование:** Когда пользователь нажимает кнопку, формируется `fetch` запрос с методом POST или PUT. Тело запроса преобразуется в JSON через `JSON.stringify`.
3. **Обновление данных:** После успешного ответа от сервера (status 200 или 204) данные в переменных обновляются (например, `lists.value = await response.json()`), и Vue автоматически перерисовывает HTML.
